# WorshipCast

**Программа для вывода слайдов на служении**: тексты песен, Библия, медиа, презентации — на проектор, сцену и в трансляцию. Локальный десктоп-софт (Electron), без обязательной подписки и без интернета для базовой работы.

![version](https://img.shields.io/badge/version-0.9.11-85b21b) ![platform](https://img.shields.io/badge/platform-Windows-555)

## Что это

WorshipCast — программа для показа контента во время церковного служения: слова песен построчно, стихи Библии, картинки/видео, PowerPoint- и Google-слайды, веб-страницы. Вывод идёт отдельным окном на второй экран/проектор, а ведущий видит панель управления с предпросмотром и списком служения.

## Возможности

- **Библиотека песен и быстрое создание** — вставляете текст песни целиком, программа сама раскладывает его по слайдам с замером по реальному шрифту (а не «на глазок»), сама собирает структуру куплет/припев/бридж. Подробности: [docs/article-quick-create.md](docs/article-quick-create.md).
- **Слайды, медиа, PowerPoint, Google Slides, веб-страницы, видеопоток** — любой из этих типов можно добавить элементом служения и переключаться между ними без остановки эфира.
- **Библия** — быстрый поиск стиха/главы, показ поверх текущего слайда, отдельный переход для появления/скрытия Библии (сам стих внутри переключается мгновенно).
- **Темы и шаблоны** — свой шаблон под шрифт, цвет, обводку, тень, положение текста; отдельно для песен и для Библии, с превью прямо в редакторе.
- **Брендовый цвет в 4 строки** — акцентный градиент приложения задаётся CSS-переменными в одном файле, меняется по всему интерфейсу сразу (см. `src/index.css`), либо настраивается прямо из интерфейса (свой градиент/один цвет).
- **Переходы** — отдельно между слайдами внутри песни, между элементами служения и при появлении Библии.
- **Авторан** — автоматическое пролистывание слайдов по таймеру.
- **Голосовое автопродвижение** — распознавание речи на устройстве (Vosk, офлайн, без отправки звука наружу) само переключает слайд, когда чтец произносит следующую строку.
- **Сценический монитор** — отдельное окно/экран для музыкантов на сцене со своей раскладкой, независимое от того, что видит зал.
- **MIDI** — управление переключением слайдов/элементов с MIDI-контроллера.
- **Пульт дистанционного управления** — управление показом с телефона/планшета по локальной сети через QR-код (`public/remote.html`).
- **Фоны служения** — картинка/видео/градиент/цвет как фон, отдельно на всё служение или по частям песни.
- **Кэш и офлайн-работа** — медиа кэшируется локально, показ не зависит от интернета.
- **Мультиязычный интерфейс** — весь UI переведён через `t('namespace.key')` (`src/i18n/ru.js`, `src/i18n/en.js`), новый язык добавляется копированием одного файла.

## Установка

Скачайте готовый установщик со страницы [Releases](../../releases) этого репозитория (`.exe`, Windows), запустите и следуйте шагам мастера установки. Интернет для запуска и базовой работы не нужен.

## Технологии

Electron · React 18 · Zustand · Vosk (офлайн-распознавание речи) · MIDI (easymidi / rtpmidi) · Supabase · electron-builder.
